# 클라우드 실제 실행 검증

공개 소스 저장소: https://github.com/Junhokim2000/journey-radar-course-2026

첫 실행: https://github.com/Junhokim2000/journey-radar-course-2026/actions/runs/42500480351

실제 GitHub Actions 실행 성공을 확인했다. 조건 1개 점검, 실행 실패 조건 0개, 차단 출처 1곳, 실패 출처 0곳, 최종 총액 미검증 표시가 10건, 검증된 목표가 0건으로 보고했다. 목표가 메일은 발송하지 않았다. 워크플로 성공은 모든 사이트의 가격 수집이나 최종 결제액 검증 성공을 뜻하지 않는다.

매시 17분과 47분(UTC)의 30분 간격 예약을 등록했다. 예약 실행은 지연·중단될 수 있다. 여행 조건·수신 이메일은 FLIGHT_MONITOR_CONFIG Secret에만 등록한다. 공개 로그에는 조건·가격·이메일 원문을 출력하지 않는다.

로컬 감시와 클라우드 감시는 별개의 작업이다. 홈페이지에서 조건을 바꾸면 클라우드 반영 버튼으로 Secret을 갱신한다. 클라우드에서 수행하는 것은 검색 감시이며 로컬 Codex 로그인이나 AI 구독 인증을 업로드하지 않는다.

최종 결제액 검증 어댑터는 아직 미완성이다. 수하물·결제수단의 조건부 요금은 별도 표시하고 미확인 비용을 0원으로 채우지 않는다.
