# 판매처 입력 단계 금액 확인

트립닷컴 검색 결과의 첫 후보를 대상으로 별도 페이지에서 같은 출국편과 조건에 맞는 귀국편을 선택합니다. 필요한 수하물이 표시된 운임과 모든 결제 방법 기준 요금을 선택한 다음, 승객 정보를 입력하기 전의 금액 상세를 읽습니다. 이름·여권·연락처를 입력하거나 다음 예약 단계를 제출하지 않습니다.

공항·날짜·성인 인원·출국 및 귀국 시각을 대조하고, 운임/세금 및 수수료/항공권 합계/발권수수료/화면 총액을 검사합니다. 수하물 표는 승객별 위탁수하물 열을 확인하고 원문·개인정보·예약 쿼리를 저장하지 않습니다.

입력 단계 총액은 bookingReview로 저장합니다. 결제 단계 추가 비용과 최종 총액이 아직 확인되지 않았으므로 purchaseVerification으로 승격하지 않으며 목표가 이메일도 발송하지 않습니다. 검색 화면 표시가와 입력 단계 총액을 홈페이지에서 따로 표시합니다. AI도 이 두 금액을 구분하도록 근거에 단계를 명시합니다.

현재 왕복 첫 출국 후보만 추가 확인합니다. 모든 출국 후보의 모든 귀국 조합을 검증한 전수 검색은 아닙니다. 시간이 없거나 접근 제한·페이지 변경·금액 불일치가 있으면 확인 실패 이유를 표시합니다.
