# 구현 및 검증 기록

목적: 반복적인 항공권 가격 조회와 조건 비교를 자동화하고, AI가 근거를 비교·설명하도록 구성한다.

2026-11-09 로컬 검증에서 CAG와 RAG를 각각 조사/독립 감사/보고의 세 역할로 실행했다. 공식 Codex CLI의 기존 ChatGPT 로그인으로 실행했으며 별도 OpenAI API 결제 키를 사용하지 않았다. 실제 MCP stdio 서버에 대한 도구 호출을 확인했다.

| 실제 모델 검증 | 역할별 별도 대화 | MCP 도구 호출 | 결과 |
|---|---:|---:|---|
| CAG 전체 자료 | 3 | 8 | 완료, 공통 후보 2개 |
| RAG 관련 자료 | 3 | 6 | 완료, 공통 후보 4개 |

근거는 2026-11-08에 직접 수집한 인천–간사이 왕복 1인(12/26–1/3)의 5개 사이트 자료다. 현재 실시간 최저가라는 의미는 아니다. 트립닷컴 358,500원, 구글 364,400원, 스카이스캐너 353,100원, 카약 350,342원, 하나투어 354,200원(회원/카드 조건부)으로 기록되었다. 모두 최종 결제 총액 미검증이다.

실제 모델은 오래된 자료, 수하물 미확인, 조건부 할인을 경고했다. 원본 근거에 없는 항공편 ID·금액, 조사와 감사가 공통으로 선택하지 않은 보고 후보를 거부하는 검사는 별도 테스트로 확인했다. 이 인위적 입력 검사는 실제 AI의 오답 사례라고 보고하지 않는다.

실제 AI가 잘못 판단한 경우 원본 캡처·출처·시각·모델 응답을 함께 보존하고, 오래된 자료/누락된 수하물/조건부 할인/시간 해석/검색 실패 중 원인을 근거로 분석한다. 실제 오답이 아직 관찰되지 않았다면 발견했다고 꾸미지 않는다.
