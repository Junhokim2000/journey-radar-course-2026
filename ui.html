알림

이메일 알림

알림을 받을 이메일과 참고 가격 수신 여부를 설정하세요. 발송 서비스 연결은 관리자가 관리합니다.

메일은 관리자가 연결한 발송 서비스를 통해 전송됩니다. 저장한 수신 주소와 알림 내용이 해당 서비스에 전달됩니다.

운임·세금·발권수수료·요청 수하물까지 확인한 입력 단계 총액이 목표 이하이면 참고 메일을 보냅니다. 최종 결제액과 예약 가능 여부는 보장하지 않습니다.

클라우드 감시는 서버 전체 최대 5개 조건을 지원합니다. 회원 조건은 수신 이메일을 저장한 후 자동 반영되며, 한도 초과 시 안내됩니다.

저장만으로는 메일을 보내지 않습니다. 인증·테스트 요청을 누르면 실제 메일 발송을 요청합니다. 실제 수신 여부는 받은편지함에서 확인하세요. 확정 총액 알림과 참고 가격 알림은 구분됩니다. 참고 가격 메일은 위 항목을 직접 켠 경우에만 발송됩니다.

클라우드 메일 발송 연결

PC가 꺼져 있어도 발송하려면 Brevo를 한 번 연결하세요. 무료 요금제를 선택하고 보내는 주소를 인증한 뒤 API 키를 입력하면 됩니다.

① 무료 가입 · ② 보내는 주소 인증 · ③ API 키 만들기

받는 주소는 위에 저장한 이메일을 사용합니다. 키는 Windows 사용자 계정에 암호화해 저장하며, 클라우드에서는 GitHub Secret으로만 사용합니다. 일반 메일 비밀번호나 키를 채팅에 보내지 마세요.

이메일·문자 알림 설정

이메일 알림

Gmail은 2단계 인증 후 앱 비밀번호를 발급해 입력하세요. 네이버는 메일 환경설정에서 SMTP를 켜고 계정 정책에 맞는 비밀번호를 사용하세요. 무료 메일 계정의 발송 한도가 적용됩니다.

휴대폰 문자 (솔라피 · 유료)

솔라피 가입·인증·발신번호 등록·잔액 준비가 필요합니다. 문자 발송은 하루 최대 5건, 이메일은 최대 50건으로 제한합니다.

위의 Brevo 발송 연결 키는 암호화해 저장합니다. 이 고급 설정의 SMTP 앱 비밀번호와 문자 API 키는 실행 중에만 보관하므로 재시작하면 다시 입력해야 합니다. 일반 계정 비밀번호나 키를 채팅으로 보내지 마세요.
